# Checklist d'implémentation

## Site public
- `index.html` est la page d'accueil active.
- `devis.html` est la page de demande de devis active.
- Les liens email, téléphone et WhatsApp sont vérifiés dans le code.
- Le responsive desktop/mobile est prévu.
- Les focus clavier et `prefers-reduced-motion` sont pris en charge.

## Avant publication
- Tester les liens internes.
- Tester le formulaire email et WhatsApp.
- Tester Chrome/Edge/Firefox et mobile.
- Lancer Lighthouse et vérifier Performance, Accessibilité, Bonnes pratiques et SEO.
- Vérifier le sitemap et les balises SEO après publication.
